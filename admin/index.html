One-time setup

Connect the dashboard

Two things have to be switched on in your Vercel project before you can sign in. Menu names in Vercel may differ slightly from the ones below.

  1. Storage for projects and images

    In Vercel, open this project, go to Storage, create a Blob store with Public access and connect it to the project.

  2. A password for this dashboard

    In Settings → Environment Variables, add a variable named ADMIN_PASSWORD. Its value is the password you will type here. Make it long.

  3. 3

    Redeploy

    In Deployments, open the menu on the latest deployment and choose Redeploy. New settings only apply to a new deployment.
